# 账号安全与减少限制风险

## 充值前

- 只从当前商品页确认价格和规则；
- 不使用来历不明的第三方脚本、插件或共享账号；
- 不把密码、验证码、恢复码、API Key 发到公开页面；
- 先确认自己购买的是账号充值还是新账号。

## 使用中

- 遵守平台使用规则；
- 不生成或传播明显违规内容；
- 不多人共用或转售账号；
- 尽量保持稳定的设备和登录习惯；
- 不进行异常批量、自动化或绕过限制的行为。

## 出现限制或异常时

- 不要反复尝试或重复付款；
- 保存订单号、时间、错误提示和套餐状态；
- 通过 OpenOBT 商品页的售后渠道咨询；
- 如果是平台侧的账号限制，应按平台提示处理，不能把“防封”理解为绕过审核。

## 重要边界

没有任何充值或账号服务能够保证永久可用或绝对不受限制。安全使用和真实披露比“永不封号”之类的宣传更重要。
